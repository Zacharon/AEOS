# Source credits and package boundary

Agentic Engineering OS is a local composition of project records, context preparation, Runner handoffs, Agentic Librarian and review practices. These references explain influences, not endorsements.

| Source | Idea and package relationship |
|---|---|
| Jake Van Clief and David McDermott, [Interpretable Context Methodology](https://arxiv.org/abs/2603.16021), v2, March 2026; [RinDig repository](https://github.com/RinDig/Interpretable-Context-Methodology) | Layered file context. Templates adapt the general method; no paper text or repository code is bundled. Paper results were not reproduced by this demo. |
| Andrej Karpathy, [LLM Wiki gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f), April 4, 2026 | Source notes and compiled knowledge. Local Librarian adds explicit Bronze/Silver/owner/Gold boundaries. Conceptual inspiration; no direct code dependency. No gist text is bundled. |
| Matt Pocock, [skills](https://github.com/mattpocock/skills), v1.3.1 | Bounded task specifications, review and handoff practices. Skill texts and their adapted local bodies are excluded from this archive. If included later, retain MIT and applicable Dex Horthy/Humanlayer credit. |
| Jesse Vincent's [superpowers](https://github.com/obra/superpowers), Ayoub Ghriss's [i-have-adhd](https://github.com/ayghri/i-have-adhd), Cathryn Lavery's [diagram-design](https://github.com/cathrynlavery/diagram-design), Affaan Mustafa's [ECC](https://github.com/affaan-m/ECC) | Design influences: verification/debugging, readable output, diagrams and context/evaluation. Adapted skill bodies/code are excluded here. |
| Python, [PyYAML](https://github.com/yaml/pyyaml/blob/main/LICENSE), [jsonschema](https://github.com/python-jsonschema/jsonschema/blob/main/COPYING) | Python is a prerequisite; Librarian imports PyYAML (MIT) and jsonschema (MIT). Dependencies are installed separately, not redistributed in this archive. |

The manifest binds exported local code to relative component paths and hashes. It does not certify authorship or grant a license. No source creator endorsement is implied. Original research bodies, external skill implementations and experimental runtimes are not distributed.
