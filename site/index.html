BEFORE YOU START

Simple tools.
Clear responsibilities.

What you need

Python 3.11+, a Markdown editor and a place for local files. Librarian uses PyYAML and jsonschema; Git is required for its approved apply/rollback flow. Windows with Python 3.14.5 is the tested setup.

How integrations work

Use a file-capable assistant such as Codex, or manually copy a bounded brief into another app and return its result. Adapter formats are included; provider authentication and live dispatch are not configured or verified.

QUESTIONS WORTH ANSWERING

Know what you're getting.

Does it run an autonomous team of agents?

No. The portable tools prepare and verify files. You or your assistant invoke the work. No model, paid service, scheduler or general worker sandbox is installed.

Can I use my existing notes and repository?

Yes. Start beside them, run the sample, and bring across only the templates and tools you choose. Keep project code in its existing repository. Never replace an existing vault wholesale.

Does verified mean approved?

No. Mechanical checks, independent review, owner acceptance and release are separate. Librarian proposals remain pending until the owner makes the exact decision.

What happens when context changes?

The handoff freshness check refuses changed or missing source files. Preserve the old evidence, inspect the change, and prepare a fresh authorized packet. A missing result is unknown, not proof nothing ran.

Is it ready to buy or publish?

This is a tested local setup preview. Pricing, commercial license/distribution terms and any support offer still need an owner decision. No customer outcomes, performance guarantees or live integrations are claimed.
