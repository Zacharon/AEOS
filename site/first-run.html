FIRST RUN

Start beside your work.

Extract the setup into a new folder. Keep an existing vault unchanged while you try the synthetic demonstration.

Install the documented prerequisites

Use CPython 3.11 or newer and PowerShell. Tested on Windows with Python 3.11.15 and 3.14.5. Run these commands from the extracted package:

$ErrorActionPreference = 'Stop'
$aeosParent = Split-Path -Parent $PWD.Path
$aeosEnvironment = [IO.Path]::GetFullPath((Join-Path $aeosParent 'aeos env'))
$aeosOutput = [IO.Path]::GetFullPath((Join-Path $aeosParent 'aeos first run'))
if ((Test-Path -LiteralPath $aeosEnvironment) -or (Test-Path -LiteralPath $aeosOutput)) {
    throw 'Choose new sibling environment/output names; existing evidence is preserved.'
}
python -c "import platform,sys; sys.exit(0 if platform.python_implementation() == 'CPython' and sys.version_info >= (3,11) else 'Use CPython 3.11 or newer')"
if ($LASTEXITCODE -ne 0) { throw 'Python version check failed.' }
python -m venv "$aeosEnvironment"
if ($LASTEXITCODE -ne 0) { throw 'Environment creation failed.' }
$aeosPython = Join-Path $aeosEnvironment 'Scripts/python.exe'
& "$aeosPython" -m pip install -r requirements.txt
if ($LASTEXITCODE -ne 0) { throw 'Prerequisite installation failed.' }
& "$aeosPython" -B scripts/check_package.py .
if ($LASTEXITCODE -ne 0) { throw 'Package integrity check failed.' }
& "$aeosPython" -B scripts/demo.py --output "$aeosOutput"
if ($LASTEXITCODE -ne 0) { throw 'Demo failed.' }

The sibling folder names contain spaces. Use new absent directory names if these already exist, and use the same environment name when continuing. START_HERE.md also records the exact interpreter and absolute paths for a fresh shell. The commands above resolve the sibling output folder to an absolute path without parent-traversal segments, as required by the demo's path check. Dependency installation uses PyPI. The demonstration itself makes no network or model calls.

Inspect what happened

Open ../aeos first run/START_HERE.md. You will find an immutable source copy, a verified-but-pending knowledge proposal, a bounded task brief and a report counting two checked sample items.

The demo also changes and removes a disposable context file, checks that review refuses it, restores its exact bytes and checks again. It never edits owner decisions or applies Gold.

Continue in a fresh session

Open PowerShell in ../aeos first run, the demonstration output folder containing vault/ and handoff/. Use the same virtual-environment interpreter as above; activation is not required:

$aeosParent = Split-Path -Parent $PWD.Path
$aeosPython = Join-Path $aeosParent 'aeos env/Scripts/python.exe'
& "$aeosPython" -B vault/09_TOOLS/agent_runner_v1/unified_handoff/handoff.py review --bundle handoff --vault-root vault

Read the candidate and its evidence. The worker's recommendation is separate from independent review and approval.

Make it your own

Copy the neutral vault into a new location. Edit the project index, state and next actions; write down your real owner, repository and allowed scope. Use the packet builder to scaffold a draft. Give the bounded brief to your assistant manually, then return the result for checking and review.

Keep source code in its existing repository. Bring across selected templates and tools after a backup; do not replace a populated vault wholesale. The archive's FIRST_RUN.md includes commands for knowledge decisions, checks and rollback.
