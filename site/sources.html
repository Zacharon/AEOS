CREDITS AND SCOPE

Build on clear sources.

The setup combines local project records, bounded context, source provenance and explicit review. These ideas have useful precedents; none of the creators below endorses this package.

Context as files

Jake Van Clief and David McDermott's Interpretable Context Methodology describes filesystem stages and inspectable agent context. The setup uses a small project record structure and separate review gates. No paper text or paper performance result is packaged as a local result.

Knowledge that can be revisited

Andrej Karpathy's LLM Wiki note discusses compiled, interlinked knowledge. The included Librarian separates raw evidence, candidate knowledge and owner-approved application. The original gist is linked, not reproduced.

Bounded engineering work

Matt Pocock's skills are a source for task-specification and handoff ideas. Upstream skill implementations are excluded from this preview.

Dependencies and terms

Python, PyYAML and jsonschema are installed prerequisites. Their own licenses apply; dependency distributions are not bundled. The archive includes source credits, exact file hashes and a draft terms notice. Commercial distribution terms and support commitments still require an owner decision.
